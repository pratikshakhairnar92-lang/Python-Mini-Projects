# Python Mini Projects

A collection of beginner-friendly Python projects demonstrating programming fundamentals, GUI development, logic building, and practical problem-solving.

## Projects

### 1. Age Predictor – GUI Application

A Python desktop application that calculates exact age using the user's date of birth.

**Features:**
- Enter date of birth (Day, Month, Year).
- Calculate age in years, months, and days.
- Interactive graphical user interface.
- Error messages for invalid dates.
- Automatic age calculation based on the current date.

**Technologies Used:**
- Python
- Tkinter
- datetime
- python-dateutil

**Run the project:**
```bash
pip install python-dateutil
python age_predict.py
```

### 2. Student Management System

A Python console-based application for managing student records.

**Features:**
- Add student details.
- View student records.
- Manage student information.
- Simple menu-driven interface.

**Technology:** Python

## 3. Attendance Tracker – GUI Application

**Description:**

Attendance Tracker is a Python-based desktop application that allows users to manage daily attendance and calculate attendance percentages through a graphical interface.

### Features
- Enter the total number of days.
- Dynamically generate an attendance table.
- Mark attendance as Present (P), Absent (A), or Leave (L).
- Count total present days.
- Calculate attendance percentage.

### Technologies Used
- Python
- Tkinter
- ttk (Combobox)

### How to Run
```bash
python attendance.py
```

## 4. Library Management System – Console Application

**Description:**

Library Management System is a Python-based console application designed to manage book records and library operations. It allows users to add, search, issue, return, and delete books through a menu-driven interface.

### Features
- Add new books with Book ID, Book Name, and Author Name.
- Display all book records.
- Search books by name.
- Issue available books.
- Return issued books.
- Delete book records.
- Calculate the total number of books.
- Colorful console interface.

### Technologies Used
- Python
- Colorama
- Lists and Dictionaries

### Installation
Install the required library:

```bash
pip install colorama
```

### How to Run

```bash
python library.py
```

### Concepts Used
- Lists and Dictionaries
- Loops and Conditional Statements
- Functions of the Colorama library
- String Methods

## 5. Student Management System – Console Application

**Description:**

Student Management System is a Python-based console application designed to manage student records. It allows users to add, view, search, and delete student information while automatically calculating percentages and assigning grades based on marks obtained.

### Features
- Add student details (Name and Roll Number).
- Calculate percentage out of 500 marks.
- Automatically assign grades based on percentage.
- Display complete student records.
- Search students by name.
- Delete student records.
- Menu-driven interface.

### Technologies Used
- Python
- Lists and Dictionaries
- Conditional Statements
- Loops

### How to Run

```bash
python manage.py
```

### Concepts Used
- List and Dictionary Operations
- If-elif-else Statements
- While and For Loops
- User Input Handling
- Percentage and Grade Calculation
