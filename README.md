# Python Mini Projects

A collection of beginner-friendly Python projects demonstrating programming fundamentals, GUI development, logic building, and practical problem-solving.

## Projects

### 1. Age Predictor – GUI Application

A Python desktop application that calculates exact age using the user's date of birth.

**Features:**
- Enter date of birth (Day, Month, Year).
- Calculate age in years, months, and days.
- Interactive graphical user interface.
- Error messages for invalid dates.
- Automatic age calculation based on the current date.

**Technologies Used:**
- Python
- Tkinter
- datetime
- python-dateutil

**Run the project:**
```bash
pip install python-dateutil
python age_predict.py
```

### 2. Student Management System

A Python console-based application for managing student records.

**Features:**
- Add student details.
- View student records.
- Manage student information.
- Simple menu-driven interface.

**Technology:** Python
