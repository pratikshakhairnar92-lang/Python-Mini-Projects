# Python Mini Projects

A collection of beginner-friendly Python projects demonstrating programming fundamentals, GUI development, logic building, and practical problem-solving.

## Projects

### 1. Age Predictor – GUI Application

A Python desktop application that calculates exact age using the user's date of birth.

**Features:**
- Enter date of birth (Day, Month, Year).
- Calculate age in years, months, and days.
- Interactive graphical user interface.
- Error messages for invalid dates.
- Automatic age calculation based on the current date.

**Technologies Used:**
- Python
- Tkinter
- datetime
- python-dateutil

**Run the project:**
```bash
pip install python-dateutil
python age_predict.py
```

### 2. Student Management System

**Technology:** Python

## 3. Attendance Tracker – GUI Application

**Description:**

Attendance Tracker is a Python-based desktop application that allows users to manage daily attendance and calculate attendance percentages through a graphical interface.

### Features
- Enter the total number of days.
- Dynamically generate an attendance table.
- Mark attendance as Present (P), Absent (A), or Leave (L).
- Count total present days.
- Calculate attendance percentage.

### Technologies Used
- Python
- Tkinter
- ttk (Combobox)

### How to Run
```bash
python attendance.py
```
